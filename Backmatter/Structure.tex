\section{Workflow from QGIS to CaWaQS Output}

This diagram describes the typical execution flow when a user triggers a computation in the CaWaQS-ViZ QGIS plugin.  
It highlights how the shared \texttt{HydrologicalTwin} instance, created once in \texttt{ExploreData}, propagates through all dialogs and backend services.

\subsection{Description of Workflow Steps}

\begin{enumerate}
    \item \textbf{QGIS Plugin / UI}  
    The user interacts with the QGIS interface and triggers an action (e.g., plot simulation, compare sim/obs, calculate statistics).

    \item \textbf{ExploreData Initialization}  
    Upon project load or at first use, \texttt{ExploreData.get\_instance()} is called.  
    \texttt{ExploreData} constructs a new \texttt{HydrologicalTwin} (HT) using configuration from the project.

    \item \textbf{HydrologicalTwin Singleton}  
    The HT instance encapsulates backend services and domain objects. It is stored inside \texttt{ExploreData} and reused by all dialogs.  

    \item \textbf{Dialog Scripts}  
    When the user activates a dialog (e.g., “Compare Sim/Obs”), the dialog retrieves the shared HT instance:
    \begin{verbatim}
    self.hydro_twin = self.exd.hydro_twin
    \end{verbatim}
    The dialog then calls only HT API methods (e.g., \texttt{extract\_values}, \texttt{apply\_temporal\_operator}, etc.).

    \item \textbf{Manage.* Services}  
    HT uses internal services (\texttt{Manage.Temporal}, \texttt{Manage.Budget}, \texttt{Manage.Spatial}) to:
    \begin{itemize}
        \item read simulation matrix and convert to DataFrame,
        \item perform temporal aggregation (e.g., annual mean),
        \item compute budgets,
        \item execute spatial operators (e.g., catchment cells).
    \end{itemize}

    \item \textbf{CaWaQS Simulation Output Files}  
    Backend services read CaWaQS binary simulation outputs and convert them to usable time series or spatial tables.

    \item \textbf{Observation Files}  
    Services also read observed time series files, align them with simulation output periods, and return them for comparison or statistics.

    \item \textbf{Back to Dialog}  
    The dialog receives the processed data from HT and updates the UI: plots, tables, PDF/HTML exports, and statistical results.
\end{enumerate}
